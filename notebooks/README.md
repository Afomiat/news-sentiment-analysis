# Notebooks

This directory contains Jupyter notebooks used for data exploration, visualization, and model experimentation.

## Contents
- `task1_eda.ipynb`: Exploratory Data Analysis. 
    - Time-series frequency analysis.
    - Headline length and word count distribution.
    - Most common keywords and N-grams.
    - Publisher activity and domain extraction.

## Usage
To run the notebooks, ensure you have activated your virtual environment and run:
```bash
jupyter notebook
```
