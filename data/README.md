# Data

Management of raw and processed datasets.

## Folders
- `raw/`: Original, unmodified data files (git-ignored).
    - `raw_analyst_ratings.csv`: The main news headline dataset.
- `processed/`: Cleaned data and engineered features ready for modeling.

## Important Note
Raw data files are excluded from version control to maintain repository performance. Ensure the files are placed in `data/raw/` locally before running analysis.
